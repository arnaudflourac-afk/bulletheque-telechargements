# Bullethèque — téléchargements

Installeurs du logiciel Bullethèque pour ordinateur, publiés automatiquement à chaque version.

- Windows : `Bulletheque-Setup.exe`
- macOS : `Bulletheque-macOS.dmg`
- Linux : `Bulletheque-Linux.tar.gz`

Le plus simple : téléchargez-les depuis « Mon compte » sur https://bulletheque.vercel.app.
Le logiciel installé se met ensuite à jour tout seul.
